# 사용자 결정 기록 (DECISIONS)

날짜순으로 쌓는다. 결정이 나면 바로 한 줄로 추가하고, 바뀐 결정은 지우지 말고 새 줄로 대체 사실을 적는다. 구현 위치를 함께 적는다.

## 2026-11-26

- **진행 방식**: 필요한 순서대로 묻지 말고 자동 진행. AWS 재배포·수집 재개도 자동 허용("응 묻지 말고 자동 허용해줘"). 결제·구독·키 발급·계정 권한 확대는 여전히 사용자가 직접 한다.
- **콘텐츠 방향**: 뉴스 전달이 아니라 한국 주식 관점의 뉴스 **분석**에 집중(저작권: 사실은 보호 대상이 아니고 표현이 보호됨, 대법원 2004도5350).
- **작성기 분리**: 글 작성 모델은 원문을 받지 않고 검증된 사실만 받는다. 규칙: 보도 사실은 출처 명시, 계산 수치는 식과 함께 표시, 단정·권유 표현 금지, 관련주마다 연결 역할 한 줄, 1차·보도 출처 구분, 투자 권유 아님 고지. → `workers/ai-processing/runtime/writer.mjs`, `docs/backlog-processing.md`
- **수집 구조(방향)**: 발견은 Finlight(국내)·GNews(미국)·텔레그램 링크. 근거는 국내 DART·기업 보도자료·IR·텔레그램 리포트, 해외 IR·공시·보도자료를 우선. 발견 API의 요약·본문은 근거로 쓰지 않는다. → `discovery.mjs`
- **유료 구독**: 지금은 구독하지 않는다(권고). AI 처리 실연결과 무료 입력 검증 후, 빈틈이 보이면 서면 약관 확인 뒤 검토.
- **방문 간격**: 같은 사이트 최소 5초 + 랜덤 0~3초(5~8초), 다른 사이트 사이 1~3초. 접속 위장·차단 우회는 하지 않는다. → `scripts/providers/pacing.mjs`
- **텔레그램**: 상시 수집, 새 글이 올라왔을 때만. 조용한 채널은 10→20→30분 간격. 이후 "지금부터 신규만": 채널 첫 방문은 시작점만 기록하고, 그 이후 게시물의 링크만 저장. 이미 저장된 링크는 7일 TTL로 만료. → `telegram-link-worker.mjs`
- **보관·삭제**: 원문 본문은 분석 완성·중복·제외 시 즉시 삭제(미완료는 최대 7일). 사실·짧은 인용·출처 기록 30일. 미게시 초안 30일(원문 만료와 무관). 출처 철회 시 즉시 회수. → `store.mjs`
- **시트**: 상위 섹터 11개는 HTML 시안(`prototype.html`)의 parent 매핑을 따른다(코드 카탈로그와 일치). 카테고리 탭 하단의 기업 표 사본은 무시. "검색페이지 설명글"은 검색 결과에 보이는 설명글.
- **하네스·팀**: 가벼운 구조. 맥락은 `docs/context/` 세 파일, 완료 기준은 `verify:integration`, 검수는 PR 단위. 팀은 통합 담당 1 + 영역별 작업 세션 최대 2~3(수집기·운영 / AI 처리 / 앱·어드민), 파일이 겹치지 않을 때만 병렬.
