# 수집·기사 작성 후속 단계 요구사항

2026-11-15 사용자 보완 요구를 후속 8단계 수집·9단계 분석/작성 계획에 이관하기 위한 기록이다. 현재 봇 구현·실수집·게시 완료 기록이나 기존 공급 게이트의 승인이 아니다. 기존 동결 기획 사본과 검수 완료 계획은 수정하지 않는다.

## 수집 대상과 경로

원본 시트의 전체 사이트·증권사 리포트·텔레그램 등록부를 대상으로 한다. 현재 동결 기준은 3단계의 106행·112 URL이며 최신 시트와의 차이는 별도 검증한다. 텔레그램만 수집하는 서비스로 축소하지 않는다. 사이트는 증권·국내/해외 증시 등의 실제 목록과 원문을 구분한다. 같은 URL에 탭이 있으면 등록된 navigation_path와 adapter 버전으로 목록 범위를 확인한다.

텔레그램은 메시지 안의 원문 링크를 1차로 사용한다. 링크가 없을 때는 허용된 최소 기업·산업·사건 표현으로 원문 뉴스 검색을 수행한다. 원문을 확인하지 못한 메시지를 기사나 독립 보도 근거로 대체하지 않는다. 경로별 권한·기술·품질 상태와 예산을 유지한다.

## 동일 기사와 매체 우선순위

매체·경로별 우선순위는 수집 스케줄과 중복 그룹의 대표 출처 선택에 사용한다. 동일 문서의 canonical URL·원출처·통신사 전재·보도자료/리포트 재인용 계보를 확인하고 하나의 문서/사건 그룹으로 관리한다. 별도 URL과 사이트 개수만큼 독립 근거가 늘어난 것으로 계산하지 않는다.

접근·이용이 허용되고 같은 사실/판본을 확인할 수 있는 후보 사이에서 설정한 매체 우선순위를 적용한다. 확인된 원출처와 공식 자료, 정정된 최신 사실, 검증 가능한 근거를 낮은 순위라는 이유로 버리지 않는다. 대표 선택 사유와 정책 버전을 기록한다. 최초 발견 시각·원문 발표 시각·수집 시각·기사 최초 게시 시각을 구분한다. 늦게 도착한 상위 매체의 동일 기사는 기존 그룹의 대표 출처/근거만 갱신하며 새 글·새 사건·새 독립 근거로 만들지 않는다.

매체 수집 우선순위와 앱 홈 이슈 순위는 별도다. 상위 매체에 실렸다는 이유만으로 홈 점수를 올리거나 최초 게시 시각·중요 변경 시각을 새로 만들지 않는다. 홈은 기존 시장 구간·사건 중요도·한국 전달 경로·유효 시세/조회 지표 계약을 유지한다. 중복 그룹은 한 번만 노출한다.

## 원문과 구분되는 상세 작성

원문 표현을 그대로 붙이거나 문장별 유사어 치환으로 작성하지 않는다. 출처별 확인된 사실·수치·발표일·공급 주체·미확정 주장과 근거 ID를 먼저 추출한 뒤, 별도 아웃라인과 문장으로 한국 주식시장 관점의 핵심 이슈·섹터 영향·조건·리스크를 작성한다. 제목·머리말·본문·표현의 배열도 검토한다. 원문의 전망이나 익명 의견을 확정 사실로 바꾸지 않는다.

게시 전 원문 대비 연속 문구·문장 및 구성 중복, 수치·명칭 일치, 사실 근거를 함께 검사한다. 상용구·기업명·필수 전문용어와 원문 고유 표현을 구분한다. 과도한 표현 중복은 재작성 후 재검사하고, 해결되지 않거나 근거/이용 범위가 부족하면 HOLD한다. 검사 방법·모델·정책 버전과 판정 사유를 남긴다. 유사도 수치 하나 또는 출처 링크만으로 저작권·이용 허가가 해결됐다고 판정하지 않는다. 기준 수치와 평가세트는 9단계 계획·검수에서 확정하며 현재 임의의 합격률을 만들지 않는다.

## 신규·갱신·새 방향

동일 사건·동일 방향의 전재와 재인용은 신규 등록하지 않는다. 검증된 수치나 추가 디테일은 기존 상세의 새 버전으로 갱신하고 변경 이력을 남긴다. 한국 영향 경로·행동 주체·정책/실적 결과 등 실질적으로 새로운 방향이 확인될 때만 기존 Story에 연결된 별도 Issue를 만들 수 있다. 표현 변경이나 상위 매체 재보도만으로 NEW_ANGLE을 만들지 않는다. 단순 갱신은 홈 재상승·알림 재발송 사유가 아니다.

## 후속 계획의 필수 검증 사례

1. 여러 사이트의 같은 통신사 기사가 하나의 원출처·문서 그룹과 하나의 홈 항목으로 합쳐지는지.
2. 하위 우선 매체에서 먼저 발견하고 상위 우선 매체가 늦게 도착해도 기존 글과 최초 게시 시각을 유지하는지.
3. 상위 매체의 옛 판본보다 확인된 정정 사실이 우선하고, 충돌 사실은 자동 덮어쓰기 대신 재검증되는지.
4. 단순 추가 디테일은 기존 버전 수정, 새로운 영향 방향은 별도 Issue로 구분되는지.
5. 원문 문장 복사·문장별 치환·고유 구성 모방을 보류하고, 독립 작성 결과도 사실 근거를 잃지 않는지.
6. 원문 접근·분석·표시 권한 미확인 경로가 실제 수집/작성/게시 단계로 넘어가지 않는지.

진행 순서는 현재 6D 구현 검증·독립 검수 → 6E 예약/알림 계획·구현 → 7단계 종목/시세/캘린더 → 8단계 전체 등록부 수집 → 9단계 분석·독립 작성·게시다. 각 단계는 계획 검수, 구현, 자체 검증, DUAL 검수, 정확한 바이트 커밋·백업 푸시 순서를 따른다. 미확정 공급 경로는 사유를 남긴 상태로 유지한다.
