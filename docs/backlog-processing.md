# 저장 링크 → 원문 확인 → 선별 → AI 상세 초안

이번 단계는 중지된 수집기를 재시작하지 않고 저장된 링크를 처리하는 별도 실행 경로다. 기존 합성용 PostgreSQL 계약을 실제 연결인 것처럼 바꾸지 않는다. 별도 SQLite에 원문·처리 이력·초안을 보관하고, 기존 Supabase·관리자·홈·앱 게시를 변경하지 않는다. 결과는 DRAFT이며 자동 게시 권한이 없다.

## 처리 흐름

1. `import`: 저장된 Telegram/웹 SQLite를 읽기 전용으로 열고 정규화 URL당 하나의 작업을 만든다. 여러 채널에서 발견한 이력은 별도로 남긴다. 재수입으로 진행 상태·완료 결과를 초기화하지 않는다. 목록·채널에 재접속하지 않는다.
2. `FETCH`: 정확한 원문 호스트의 명시된 내부 검토 정책과 현재 철회/만료/제외를 확인한다. robots → 개별 원문을 호스트당 최소5초로 순차 방문한다. robots 규칙은 SQLite에 하루 보관하여 재시작·`--once`에서도 이어간다. 공개 DNS 전부 검사·고정, HTTPS/TLS, 요청8초·HTML2MiB·본문4만자 및 UTF-8 60,000바이트, 최대4회 이동을 제한한다. 이동 대상 호스트에도 정책이 있어야 한다. 명시된 유료 접근 표시·로그인·유료벽·CAPTCHA·인증거절은 보류한다. 메뉴 전체를 기사 본문으로 추정하지 않는다.
3. `TRIAGE`: 광고·금융상품 홍보, 가격·수급 요약만 있는 글, 한국 섹터/주식시장 매크로 밖의 글은 제외한다. 불확실하면 보류한다. 원문에서 그대로 찾을 수 있는 짧은 근거 구간과 사실·숫자·단위·기간·사건 정보를 추출한다. 모델에게 DB/게시/외부 도구를 주지 않는다.
4. `DRAFT`: 같은 사건 근거를 묶는다. ordinary fact는 확인된 취재/공식 원문, 중대 매크로는 공식1 또는 계보·편집국·소유그룹이 모두 다른 확인된 원문3을 요구한다. 같은 원문의 여러 주소·같은 본문은 독립3개가 아니다. 미확인 익명 주장·수치 충돌·날짜 미확정은 보류한다. 검증된 사실 묶음으로 한국 주식 관점의 상세를 작성한다.
5. `VERIFY`: 다른 검증 모델의 별도 호출로 사실·날짜·기업/섹터 경로·수치·글을 검토한다. 정확한 근거 인용·등록 ID·수치 비교·원문 표현 중복 검사도 별도로 적용한다. 원문 제목/문장을 길게 복제한 글은 통과시키지 않는다. 원문 겹침 검사 통과가 저작권이나 사실의 정확성을 보증하는 것은 아니다.
6. 같은 본문·사실·방향을 이미 처리했다면 모델을 다시 부르지 않는다. 같은 안건/같은 영향 방향에 새 사실이 추가되면 기존 초안 ID·최초 시각을 유지하며 버전을 올린다. 영향 섹터·방향·경로 분류가 달라지면 새 방향 초안을 만든다. 제목 유사도만으로 병합하지 않는다. 충돌·기존 버전 변경·수동 보호에는 제안/보류로 남긴다.

본문이 달라도 선별 후 같은 사건·사실 ID·방향이면 작성·검증 호출 전에 중복 처리하고 출처만 추가한다. 최초 시각·버전·갱신 시각을 올리지 않는다. 한 사건에 원문8개 또는 사실80개를 넘으면 맥락 축소를 임의로 하지 않고 보류하여 기존 초안을 보존한다. 모델 입력 길이 초과도 호출 예약·과금 이전에 보류한다.

카탈로그/정책 변경으로 이전 근거가 현재 분석 묶음에서 빠진 경우에도 기존 사실을 누락한 UPDATE는 허용하지 않는다. 수치는 값과 단위를 함께 대조하고 단위가 값 필드에 섞인 형식을 거절한다. HBM4 같은 정확히 인용된 영문 제품 식별자는 단위 없는 범주 값으로 구분한다. USD의 달러·$ 표기는 대조하되 %와 %p는 별개다. 일정은 인용된 현지 날짜·시간·명시된 시간대(또는 원문의 ISO 실제 시각)와 eventAt·timezone이 일치해야 한다. 시간대가 불명확하면 일정을 추정하지 않는다. 출처 정리 시 해당 원문에 의존하는 제안만 삭제하고 무관한 편집 제안은 유지한다.

독립3곳 판단에는 호스트 정보만으로 충분하지 않다. `documentOrigins`에 정확한 URL·본문 해시·본문에 존재하는 계보 근거 quote·검증된 originGroupId를 결속한 항목이 있어야 그 원문을 독립 출처로 센다. 서로 다른 사이트라도 같은 통신사 전재이면 originGroupId가 같아야 한다. 해당 검증 자료가 없으면 독립3곳 경로는 보류하며 공식 원문1개 경로만 가능하다. 이 계보 확인의 자동화는 후속 연동 대상이다.

## 상세 형식과 한계

핵심 이슈·한국 관점 분석·수혜/피해/관련 섹터·기업·긍정 또는 긍정/부정 시나리오·리스크·근거 있는 미래 일정·원문 출처를 저장한다. 피해만 있으면 시나리오를 숨기고 리스크를 요구한다. 관련 섹터는 조건부 방향을 표시하고, 일정이 없으면 일정 영역을 표시하지 않는다. 모델이 섹터의 모든 기업을 자동 추가할 수 없다.

사건 식별과 방향 분류는 근거 검증을 거친 초안용 판단이다. 실제 공개 안건 병합/정정/알림·관리자 저장/홈 순위 반영은 이번 경로에 포함하지 않는다. 발행일이 불명확하거나 오래된 사건을 새 사건으로 쓰려는 경우 보류한다. PDF는 바이트를 안전하게 넘기는 `extractPdf` 포트가 있지만 실제 PDF 추출기가 설정되지 않으면 `PDF_EXTRACTOR_REQUIRED`로 보류한다. HTML을 PDF 원문으로 완료 처리하지 않는다.

## 재시작·중복·보관

작업 lease와 SQLite 트랜잭션으로 동시에 같은 작업을 확정하지 않는다. 모델 호출 전에 문서/단계/입력/정책/카탈로그/모델을 결속한 INTENT를 저장한다. 응답이 불명확하거나 중간에 재시작하면 UNKNOWN으로 두고 다른 프롬프트/모델로 자동 재호출하지 않는다. 확정된 결과는 재사용한다. 모델 거절·예산 소진과 응답 불명을 구별한다. API 요청은 자동 재시도하지 않는다.

HTTP 5xx·408 등 처리 여부를 모르는 응답은 UNKNOWN이다. 완료된 명시적 거절은 REJECTED이며 자동 재시도하지 않는다. 원문 출처 철회/만료 시 작업 payload의 인용·상세, 관련 제안, 모든 의존 모델 응답도 비운다. 복수 원문 중 하나가 철회되면 안전을 위해 관련 결과를 보류한다. 삭제된 응답을 같은 입력으로 유료 재생성하지 않는다.

원문은 출처별 허용 기간과 링크 보관 기간 중 짧은 기간만, 최대7일 보관한다. 원문·모델 결과·초안은 내부 검토용이며 개인정보/원문/키를 로그에 남기지 않는다. 모델 INTENT/UNKNOWN의 내용 없는 식별 기록은 불명 재호출 방지를 위해 남긴다. 수집 flag와 처리 실행 flag는 별개이며, 기본 예시는 둘 다 OFF·호출 예산0이다.

## 사용

```powershell
node --experimental-strip-types workers/ai-processing/runtime/cli.mjs import --db .local-data/backlog/processing.sqlite --telegram .local-data/backlog/telegram-snapshot.sqlite
node --experimental-strip-types workers/ai-processing/runtime/cli.mjs status --db .local-data/backlog/processing.sqlite
```

실제 처리에는 현재 관리자 카탈로그, 호스트별 명시된 내부 검토 정책/근거, 원매체 계보 정보, 모델3종 설정과 `JUDOJU_ANALYSIS_OPENAI_API_KEY`가 필요하다. 문의 이메일이나 기존 Supabase 키를 AI 키로 재사용하지 않는다. 키는 비공개 환경에서만 주입하고 채팅/저장소에 넣지 않는다. `config.example.json`을 비공개 경로에 복사해 설정한 뒤 원문/모델 각 실행 flag를 명시해야 한다.

```powershell
node --experimental-strip-types workers/ai-processing/runtime/cli.mjs work --db .local-data/backlog/processing.sqlite --config .local-data/backlog/config.json --once --execute-originals --execute-models
```

모델 어댑터는 OpenAI Responses의 strict JSON schema, `store:false`, 제한된 출력과 실행 시간을 사용한다. 모델 이름·키·요금제를 임의로 선택/결제하거나 실제 API를 자동 호출하지 않는다. [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
