## 사용자 확정 — 주도주뉴스 신규 제품 분리

식자재 관리앱을 사용하지 않고 새로 구성한다. 공통계약 project-isolation과 제작 new-project 절에 전용 저장소·Expo 앱/EAS·어드민·신규 Supabase DB/인증·Docker worker/큐/volume·배포/비밀정보 분리를 명시했다. ‘단일 저장소’는 주도주뉴스 내부, ‘공통 코드’는 해당 Android/iOS 사이의 공유다. 기존 제품은 변경하지 않으며 공용 설치 도구만 사용할 수 있다. project_resource_manifest 실제 대상 대조를 0~4/12단계에 연결한다. 실제 저장소·클라우드 자원을 생성한 것은 아니다. 변경 전 문서는 ../plan-unified-archive-before-isolation-20261113/에 보존한다.

- UC-ISO-01: 로컬 Supabase의 project_id·전체 활성 포트·컨테이너/volume·제품 식별을 추가하고 불명 endpoint의 쓰기·migration 금지, 신규 설정만 포트 변경 기준을 명시했다.
- UC-ISO-02: 0/2/4/12단계 표 및 P08/P12에 제품 분리 증거를 연결했다. release_manifest가 project_resource_manifest 버전/해시를 참조하며 미생성/PENDING 자원은 해당 연결 게이트를 통과하지 않는다.
