## 공통 실행 규칙

- 주기 수치의 단일 기준은 본문 4절이다. 아래 행별 schedule_class로 적용하며 이 부록에서는 수치를 다시 정의하지 않는다. 도메인·권한 한도가 우선하고 목록 폴링·24시간 이벤트 기반 분석/게시/정정·10분 홈 갱신은 별도다.
- 리포트는 목록 메타데이터로 기업·산업·작성일·보고서 ID 확인 후 허용된 PDF만 처리한다. 통합 목록은 한 번 요청해 항목 유형별로 분기한다.
- Telegram: 권한 확인 전 연결·다운로드·AI 분석 비활성. 허용된 경우에만 이벤트 수신과 누락 재조회를 설계하고 수정/삭제 메시지 판본을 구분한다. 채널 가입이나 개인 계정 공유가 허가를 대신하지 않는다.
- 목록은 새 후보 탐색, 상세/공식 자료는 근거 검증용. 같은 URL·원문 ID·판본은 재사용한다. PASS·HOLD·UPDATE·NEW_ANGLE·철회 처리와 보관은 본문 5~13절을 따른다.
- 목록 분류·탭·페이지네이션·시각대·본문 추출·재전재 원출처를 먼저 시험한다. 인증·결제·보안프로그램을 우회하지 않는다. 접근 불가/본문 미확보를 0건 정상으로 처리하지 않는다.
- 홍보·수급 시황·시장 무관 기사는 제목/머리말 우선 선별한다. 새로운 정책/공시 사실이 섞이면 그 사실을 재평가한다. 종합 경제/산업 목록은 한국 섹터 또는 시장 전체 전달 경로 검증을 통과해야 한다.
- 이 부록의 활성 상태는 제안이며 시트 원본을 수정하지 않았다. 시트 기재 URL은 그대로 보존하고 최종 API/RSS/렌더링 경로는 사전검사 후 별도 필드에 등록한다.

- origin_resolution_rule은 기사별 원출처를 확인하는 최소 정책이다. NEWSROOM_VERIFY도 직접 취재를 보장하는 인증이 아니며 전재·동일 소유 그룹·인용 계보를 매번 검사한다. 미확인 그룹/원출처는 주요 매크로 독립3곳에 세지 않는다.
